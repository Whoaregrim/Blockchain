# Blockchain для бизнеса

Этот репозиторий содержит минимальный пример блокчейна (уровня MVP), который можно использовать как основу для бизнес-проекта: учёт транзакций, проверка цепочки, базовая система консенсуса Proof-of-Authority (PoA) с фиксированными валидаторами. Для сценариев приёмки можно хранить бизнес-атрибуты (например, номер вотчера/накладной и цвет метки) в поле `metadata`.

## Что внутри
- `src/blockchain.py` — реализация блоков и цепочки, поддержка `metadata` в транзакциях.
- `src/app.py` — небольшой CLI-скрипт для работы с цепочкой.

## Быстрый старт

```bash
python src/app.py
```

## Что нужно уточнить для боевого решения
1. **Тип сети**: приватная, консорциумная или публичная.
2. **Консенсус**: PoA/PoS/другая модель и как управляются валидаторы.
3. **Тип данных**: какие бизнес-сущности и какие поля должны быть неизменяемыми.
4. **Интеграции**: ERP/CRM/1С/BI и способы чтения/записи.
5. **Регуляторика**: хранение персональных данных и требования к аудиту.
